# Jokenpô (Pedra, Papel e Tesoura) em Python

Um clássico jogo de **Jokenpô** desenvolvido em **Python** utilizando a biblioteca gráfica **Tkinter**  O objetivo deste projeto foi praticar lógica de programação, manipulação de interfaces gráficas (GUI) e tratamento de eventos em Python.

##  Tecnologias Utilizadas
* **Python 3.x**
* **Tkinter** (para a interface gráfica)
* **Random** (para a escolha aleatória do computador)
